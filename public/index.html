How it works

Press the bubble in the corner and just talk. Everything below is wired up in this demo — no mock screens.

Speak or type

Tap the mic, speak, and it stops on its own when you finish. Or type — the reply is still spoken.

Natural voice

Neural voice for Urdu and English, streamed sentence by sentence so the reply starts in about a second.

Books the slot

Checks real availability and writes the appointment, then hands you a WhatsApp confirmation.

Escalates

Asks for a human, or mentions bleeding or swelling, and it stops selling and puts the clinic on the line.

What is running behind it

All free-tier friendly. Swap any piece by changing one environment variable.

Ears — Groq Whisper

Speech to text, ~300 ms, 8 audio hours a day free. Falls back to the browser's own recogniser when no key is set.

Brain — Groq gpt-oss-120b

Tool calling for availability, booking and hand-off. 1,000 requests a day free.

Voice — Azure Neural

ur-PK-UzmaNeural and ps-AF-LatifaNeural, 500k characters a month free, cached so repeats cost nothing.

GET /api/health     which providers are actually configured
POST /api/chat      SSE stream: delta · tool · card · done
POST /api/stt       base64 audio -> text
POST /api/tts       text -> audio/mpeg
GET  /api/book      next open slots
POST /api/book      create a booking (for the site's own form)

Adding it to tanveerkhokar.vercel.app

One script tag at the end of <body>. No rebuild of the clinic site, no access to its source needed.

<script
  src="https://tkdent-voice.vercel.app/widget.js"
  data-api="https://tkdent-voice.vercel.app"
  data-lang="en"
  data-langs="ur,en"
  defer></script>

Or drive it from an existing button: TKDentVoice.open(), TKDentVoice.ask("book a cleaning").
